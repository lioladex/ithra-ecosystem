# Memory & Transformation Mechanics — Confluence

แปลงจาก `data/memoryMechanics.js` (`MEMORY_MECHANICS_HTML`) — กฎ canon ของกลไกความจำและการเปลี่ยนร่างของตัวเอก (Confluence) ต้องเช็คไฟล์นี้ก่อนเขียนฉากที่เกี่ยวกับสัญชาตญาณข้ามร่าง, การเปลี่ยนร่าง, หรือพัฒนาการความทรงจำ

---

Confluence ไม่ได้ "จำ" ในความหมายทั่วไป — มันสะสม **"ความรู้สึกว่าอะไรถูกต้อง"** ตลอด 2,000 ล้านปีก่อนจุดตื่นรู้ ไม่มีภาพ ไม่มีเสียง ไม่มีลำดับเวลา มีเพียงแรงผลักดันอัตโนมัติที่ก่อตัวจากการทำสิ่งเดิมซ้ำนับล้านครั้ง

## กฎอิทธิพลของร่างเก่า

| ✓ ส่งต่อได้ | ✕ ส่งต่อไม่ได้ |
|---|---|
| จังหวะและรูปแบบการเคลื่อนไหว | ภาพของร่างเก่าหรือสถานที่ |
| ความรู้สึกว่าอะไรเป็นภัย/ไม่เป็นภัย | ชื่อ เสียง หรือลำดับเหตุการณ์ |
| แรงผลักให้เข้าหาหรือถอยหนี | ความเข้าใจว่า "ฉันเคยเป็นสิ่งนั้น" |
| ความรู้สึกคุ้นเคยกับสถานการณ์บางแบบ | **ความรู้ว่าร่างปัจจุบันทำอะไรได้/ไม่ได้** |

**ข้อสุดท้ายคือจุดอันตรายที่สุด** — สัญชาตญาณจากร่าง Vorthak สั่งให้ "ยืนหยัดและปะทะ" โดยไม่มีข้อมูลว่าร่างปัจจุบันหนักเท่าไหร่หรือมีอาวุธหรือไม่ เป็นคำสั่งที่ไม่ผ่านการตรวจสอบความเป็นไปได้เลย

> ใช้กฎนี้กับ ability เชิง "ความจำข้ามร่าง" ในไฟล์ creature ด้วยได้ (ตัวอย่างจริง: ability "การอาบแสงด้วยปีกแทนแผงคอ" ของ Skyther ใน `creature-design.md`/`creatures/skyther.js` — แรงผลักดันให้อาบแสงส่งต่อมาได้ แต่ความรู้ว่าร่างนี้ไม่มีแผงรับแสงแบบ Luvenn ส่งต่อไม่ได้ ร่างจึงด้นสดใช้ปีกแทน)

## พัฒนาการความทรงจำ 5 ระยะ

| ระยะ | ช่วง | รายละเอียด |
|---|---|---|
| 0 | ก่อนตื่นรู้ (2,000 ล้านปี) | ไม่มีความทรงจำใดๆ ทั้งสิ้น มีแต่ปฏิกิริยาอัตโนมัติล้วนๆ |
| 1 | ตื่นรู้ (จุดเริ่มเรื่อง) | เกิดความสามารถ "หยุดและรู้สึกถึงความรู้สึกตัวเอง" เป็นครั้งแรก ยังจำอะไรไม่ได้เลย |
| 2 | ยุคความรู้สึกนำทาง (1,000-3,000 ปี) | ตอบสนองตาม "ความรู้สึกว่าอะไรถูกต้อง" — ช่วงที่ยาวนานและเปราะบางที่สุด มีสติแต่ยังไม่มีความทรงจำเรียนรู้จากความผิดพลาด |
| 3 | ความทรงจำแรก (หลายพันปีต่อมา) | เริ่มจำจากเรื่องพื้นฐานที่สุด: "สิ่งนี้กินได้ / กินไม่ได้" |
| 4 | ความทรงจำเชิงเหตุการณ์ | เริ่มมีสำนึกเรื่องเวลา — เงื่อนไขจำเป็นของคำถาม "ฉันเคยเป็นอะไรมาก่อน" |

## กฎการเปลี่ยนร่าง (CELLULAR RE-TEMPLATING)

Confluence ไม่ได้ "สิง" ร่างของสิ่งมีชีวิตอื่น — มัน **จำลองแม่แบบขึ้นใหม่ในระดับเซลล์** ร่างต้นแบบยังมีชีวิตอยู่ต่อไปตามปกติ ไม่มีอะไรถูกพรากไปจากมัน (ดู field `switchHost` ใน `data/journey.js`)

| เงื่อนไข | รายละเอียด |
|---|---|
| 1. สัมผัสโดยตรง | ต้องมีการสัมผัสร่างต้นแบบจริงๆ — เห็นจากระยะไกลหรือได้กลิ่นไม่พอ ระยะประชิดถึงขั้นเนื้อแตะเนื้อเท่านั้น |
| 2. ตัวกระตุ้น | ต้องมีแรงกดดันต่อการอยู่รอดในจังหวะเดียวกันนั้น (บาดเจ็บหนัก ถูกไล่ล่า เหลือตัวเดียว) แรงกดดันนี้คือสิ่งที่สั่งให้เซลล์เริ่มผลัดเปลี่ยน |
| 3. ไม่มีการเลือก | ในยุคนี้ Confluence ยังเลือกไม่ได้ว่าจะเปลี่ยนเป็นอะไรหรือจะเปลี่ยนเมื่อไหร่ ร่างกายตัดสินใจเอง มันรู้ตัวอีกทีก็ตอนที่ทุกอย่างจบไปแล้ว |

ฉาก T+8 (`shock-collapse` → `transformation` ใน `data/journey.js`) เข้าเงื่อนไขครบทั้งสามข้อพอดี — ขาถูกงับไว้ (สัมผัสโดยตรง) ฝูงแตกไปหมดจนเหลือตัวเดียว และยังมีภัยอยู่ตรงหน้า (ตัวกระตุ้น) ร่างจึงผลัดเปลี่ยนเองโดยที่ตัวเอกไม่ได้สั่งและไม่เข้าใจว่าเกิดอะไรขึ้น

**สิ่งที่จะเปลี่ยนไปในอนาคต** — เมื่อ Confluence สะสมความทรงจำมากพอจนเข้าใจกลไกนี้ด้วยตัวเอง เงื่อนไขข้อ 3 จะหายไป มันจะเลือกร่างได้ตามความนึกคิดโดยไม่ต้องรอให้เกือบตายก่อน (ตอนนี้ยังห่างจากจุดนั้นมาก — อย่าเขียนให้ Confluence เลือกร่างได้เองในบทที่ยังไม่ถึงจุดนี้)

## เส้นเวลาฉากตื่นรู้ (T-0 → T+7)

| Tag | ชื่อ | เหตุการณ์ |
|---|---|---|
| T-0 | ฝูงอาบแสง | ฝูง Luvenn กางแผงคอรับแสงพร้อมกัน — ร่างกายที่อิ่มแสงแผ่ความร้อนออกมาโดยไม่รู้ตัว |
| T+1 / T+2 | ถูกล้อม → สัญญาณเตือน | ฝูง Karvos ล้อมเงียบจากชั้นพื้นดิน ฝูง Luvenn จับแรงสั่นได้และแตกกระจายวิ่งหนี |
| T+3 ⚡ | ภาพซ้อนทับ | ตัวเอกเห็นเงาร่าง Karvos ตรงกับ Thessek ทุกประการ — สัญชาตญาณ Vorthak สั่ง "ยืนหยัดไว้" ปะทะกับสัญชาตญาณ Luvenn ที่สั่ง "หนี!" ร่างกายค้างกลางก้าว |
| T+4 | สวนกลางอากาศ | รอ Karvos ลอยกลางอากาศแล้วยกขาหน้ากระแทก — น้ำหนัก 310 กก. ปะทะ 58 กก. ทำให้กระเด็นบาดเจ็บสาหัส |
| T+5 / T+6 | ถูกรุม → ฝูงแตก | ใช้จังหวะเข้า-ออกของ Vorthak รับมือ 5 ตัวที่เหลือ จนฝูงตื่นกลัวและถอยหนี |
| T+7 ★ | ความเงียบ — สติดวงแรก | ยืนแน่นิ่งเพื่อ "รู้สึกถึงสิ่งที่เพิ่งเกิดขึ้น" เป็นครั้งแรกในชีวิต — จุดกำเนิดของสติปัญญา |

**หัวใจของฉาก** — ตัวเอกไม่ได้รอดเพราะแข็งแกร่ง แต่รอดเพราะมี *ความรู้ที่ไม่ควรมีในร่างที่ไม่ควรมีความรู้นั้น* การไม่เข้าใจว่าตัวเองรอดมาได้อย่างไร คือคำถามแรกที่จุดชนวนทุกอย่างต่อจากนี้ — คำถามนี้ยังไม่มีคำตอบในเนื้อเรื่องจนถึงตอนนี้ (ดู `codex/chapter3-redesign-draft.md` — บทที่ 3 กำลังเดินเข้าใกล้คำถามนี้จากอีกมุม แต่ยังตั้งใจไม่ตอบ ตามกฎข้อ 12 ใน `writing-style.md`)

## ห้ามเอ่ยชื่อจริงในเนื้อเรื่อง

กลไกทั้งหมดข้างบนนี้ (Vorthak, Thessek ฯลฯ) เป็นข้อมูล**สำหรับผู้เขียน/นักวิเคราะห์**เท่านั้น — ในตัว `paragraphs`/action `text` จริงของ `data/journey.js` ห้ามเอ่ยชื่อสปีชีส์จริงเหล่านี้เด็ดขาด (กฎข้อ 2 ใน `writing-style.md`) ให้คงความคลุมเครือแบบ "สัญชาตญาณหนึ่ง"/"เงาที่คุ้นเคย" ไว้เสมอ — Confluence เองก็ยังไม่รู้ชื่อของสิ่งที่มันเคยเป็น
